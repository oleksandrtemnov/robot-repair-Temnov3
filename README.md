 Юніт 2: Щоденник розробника
Що зроблено:** Налаштовано керування персонажем у 2D-просторі, додано Rigidbody2D та BoxCollider2D для фізичної взаємодії з об'єктами.
Де застрягли:** Виникала помилка CS0229 через дублювання скриптів, а також конфлікт між застарілою системою введення Input.GetAxisRaw та новим Input System.
Що зрозуміли про FixedUpdate і колайдери:** Рух у FixedUpdate через MovePosition забезпечує плавність і відсутність дрижання персонажа при зіткненнях. Налаштування Collider Type = None для підлоги дозволяє вільно переміщатися без застрягання на швах тайлів.
